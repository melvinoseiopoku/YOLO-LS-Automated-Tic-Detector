# Training V1 Workspace

This folder keeps the Label Studio export, source videos, MATLAB conversion
scripts, YOLO datasets, and dataset-report outputs together so the existing
relative paths continue to work.

## Contents

- `training.json` - local Label Studio annotation export, ignored by git.
- `videos/` - local raw MP4 recordings for the target study videos, ignored by
  git.
- `yd/` - primary YOLO dataset config. Generated images and labels are ignored
  by git.
- `yolo_dataset/` - earlier/smaller YOLO export config. Generated images and
  labels are ignored by git.
- `dataset_report_figs/` - figures generated by `analyze_tic_dataset.m`.
- `dataset_report_tables/` - reserved for generated analysis tables.

## Primary Scripts

- `ls_videorectangle_to_yolo_allframes.m`
- `ls_videorectangle_to_yolo_dataset.m`
- `analyze_tic_dataset.m`
- `sanitycheck.m`
